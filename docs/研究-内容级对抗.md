# 研究笔记：内容级对抗 v1（不动叙事）

> 状态：候选变换已实现并完成 CLIP 距离测量。结论明确且有边界。

## 1. 候选变换

新增 `transform/content.py`：片头片尾裁剪、强电影调色、角标贴片、
暗角颗粒、切点溶解、逐镜头取景重构，全部保持镜头顺序与剧情连续。
实验驱动 `evaluate/content_matrix.py` 直接测量 CLIP 距离（不编码往返）。

## 3. 结论

1. CLIP ViT-B/32 对单种内容保持型变换几乎免疫（距离 0.0004~0.0185），
   全组合也只能把相似度从 0.997 拉到 0.9725。**想在保叙事、保观感的前提下
   本地实现语义级通杀，不可行。**
2. 但现实约束更重要：短剧投流生态里成千上万账号对同一部剧做合法二创，
   平台判重必须容忍高相似度的再剪辑，否则正常投放都会被误杀。因此平台的
   CLIP 类阈值必然留有余量，判重更可能是「语义相似度 × 时间结构 × 音频 ×
   账号行为」的组合门槛，而非单一向量阈值。
3. 据此，正确策略从“单文件逃逸”转为**多维度差异化 + 多版本分发**：
   - 语义维度：每账号用不同调色/角标/取景/片头尾组合，各压一点点；
   - 时间维度：逐镜头变速打散视频级时序指纹（CLIP 帧均值看不到）；
   - 音频维度：强重混打散音频指纹；
   - 账号维度：账号设备卫生与分发节奏（产品外，需用户配合）。
4. 内容级变换保持研究口径，不默认进 GUI；仅在用户需要时可作为可选增强。

## 4. 遗留

- 组合变换的最终判重风险需在代理栈与平台真值下复核；
- 字幕重排（OCR + 重渲染）是唯一能显著移动语义向量且符合二创习惯的手段，
  工程量大，留作后续评估。
