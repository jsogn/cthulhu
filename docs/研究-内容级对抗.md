# 研究笔记：内容级对抗 v1（不动叙事）

> **研究用途声明**：本文仅用于数字水印、内容指纹、媒体取证与视频变换的研究、教学和授权测试；严禁用于规避平台规则、去除版权/溯源水印、侵权搬运、账号矩阵规避或其他违法违规用途。完整边界见项目根目录 `docs/研究用途与合规声明.md`。

> 状态：候选变换已实现并完成 CLIP 距离测量。结论明确且有边界。

## 1. 候选变换

新增 `transform/content.py`：片头片尾裁剪、强电影调色、角标贴片、
暗角颗粒、切点溶解、逐镜头取景重构，全部保持镜头顺序与剧情连续。
实验驱动 `evaluate/content_matrix.py` 直接测量 CLIP 距离（不编码往返）。

## 2. 结果（0608 30s 片段）

| 变换 | CLIP 相似度 | CLIP 距离 | 对齐 SSIM | 叙事连续性 |
| :--- | :--- | :--- | :--- | :--- |
| 暗角颗粒 | 0.9994 | 0.0006 | 0.982 | 0.985 |
| 切点溶解 | 0.9996 | 0.0004 | 0.988 | 0.984 |
| 片头片尾裁剪 | 0.9947 | 0.0053 | 0.703 | 0.985 |
| 逐镜头重构 | 0.9875 | 0.0125 | 0.581 | 0.985 |
| 电影调色 | 0.9853 | 0.0147 | 0.887 | 0.981 |
| 角标贴片 | 0.9815 | 0.0185 | 0.981 | 0.985 |
| 组合 | 0.9725 | 0.0275 | 0.555 | 0.986 |

## 3. 结论

1. CLIP ViT-B/32 对单种内容保持型变换几乎免疫（距离 0.0004~0.0185），
   全组合也只能把相似度从 0.997 拉到 0.9725。**想在保叙事、保观感的前提下
   本地实现语义级通杀，不可行。**
2. 该结果只说明：在保持叙事和观感的条件下，单纯内容保持型变换对 CLIP 类
   语义嵌入的影响有限。不能据此推断真实平台的判定阈值，也不能把研究结果
   用于账号矩阵规避或平台规则规避。
3. 后续研究应转向**代理指标校准与差异分析**，而不是“单文件逃逸”：
   - 语义维度：比较不同调色/角标/取景/片头尾组合对代理 embedding 的影响；
   - 时间维度：研究逐镜头变速对视频级时序代理指标的影响；
   - 音频维度：研究音频重混对音频指纹代理指标的影响；
   - 明确边界：不得把上述组合用于规避平台规则、账号关联判定或版权识别。
4. 内容级变换保持研究口径，不默认进 GUI；仅在授权研究环境中作为可选实验项。

## 4. 遗留

- 组合变换的最终判重风险需在代理栈与平台真值下复核；
- 字幕重排（OCR + 重渲染）是唯一能显著移动语义向量且符合二创习惯的手段，
  工程量大，留作后续评估。

## 5. 字幕扰动先验实验（无依赖，2026-08-24）

用底部 30% 高对比度掩膜定位字幕带，测试四种不动文字内容的样式扰动：
对比重塑、色偏、锐化、微移位，以及其组合。

| 变换 | CLIP 距离 |
| :--- | :--- |
| 字幕对比重塑 | 0.0008 |
| 字幕色偏 | 0.0001 |
| 字幕锐化 | 0.0001 |
| 字幕微移位 | 0.0007 |
| 字幕组合 | 0.0009 |
| 字幕+全组合 | 0.0193（≈全组合本身的 0.0275，无增益） |

结论修正：**字幕样式扰动对 CLIP 几乎无效（≤0.001）**，说明 CLIP 对文字区域的
小改动高度鲁棒，场景语义主导 embedding。据此评估，完整 OCR 重排（换字体/
位置）即便成功，预计也只能移动 0.01~0.03，且带 OCR 错误与观感风险，
投入产出比不足。**建议终止字幕重排立项**，把研究主线收口到：构图级变换 +
代理指标校准 + 授权环境下的合规性观察。
