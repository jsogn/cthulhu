# recrop 替代原语摸底：研究设计

日期：2026-08-25
范围：仅替换"画面重构（recrop）"原语；其他原语与档位全部冻结。
形态：一次性摸底脚本 + 对比报告；不改产品代码，不建基础设施。

## 1. 背景与目标

现有 recrop 为"只裁左/下两边后缩回原分辨率"，保护右上角剧名，但会削到左缘水印
与低位字幕。历史探索结论：

- 几何重取样与"无感"互斥：感知哈希在 8x8~16x16 粗网格采样，小形变被平均掉，
  大平移必然留下可见补边或删除内容；blur-fill 等补边方案被否决（可见毛玻璃边）。
- 非几何域存在"哈希敏感、人眼不敏感"的结构化扰动空间（低频亮度波纹、色度微扰、
  显著性引导扰动、中频 DCT 扰动等），本摸底将其纳入候选，由数据决定。

目标：找一个候选原语，在以下三约束下优于或持平旧 recrop：

1. 对抗不降（自建代理判重栈，研究口径相对比较）；
2. 观感不劣（机器初筛 + 用户人眼终验）；
3. 效率不降。

若全部候选不达标，结论为"保留旧 recrop"。

## 2. 判定门（机器初筛）

- 对抗：四族哈希（pHash / dHash / wHash / blockhash）平均距离 >= 旧 recrop 的 95%，
  且 duplicate_risk <= 旧值 + 0.02；在"仅重构"与"完整平衡档"两种配置下都成立。
- 观感：对齐 VMAF 不劣于旧 recrop；另用边缘带梯度/对比度指标自动标记可见补边或
  涂抹（四边 3% 带的水平/垂直梯度能量显著高于原片同区即标记）。
- 效率：clip60 端到端耗时 <= 旧 recrop 路径的 1.1 倍；另附"是否可下沉 ffmpeg 原生
  滤镜"备注（geq/eq/crop 等），不作为硬门。
- 人眼：通过机器初筛者产出逐帧对比图（右上剧名、左水印、底部字幕、全屏素材），
  由用户终验；最终以人眼为准。

5% 与 0.02 容差为人为设定，报告同时给出原始数值；临界通过的候选换 seed 复跑一次。

## 3. 候选原语与参数

| 编号 | 原语 | 参数扫描 |
| :--- | :--- | :--- |
| C0 | 旧 recrop（对照） | 0.03 |
| C_NONE | 关闭 recrop（对照） | 无 |
| C1 | 低频亮度波纹（2D 正弦 + 时间缓变） | 幅度 0.8%/1.5%/2%，波长 1/2/1/2 帧宽，横/竖/对角 |
| C2 | 显著性引导块均值微扰 | 16x16 块，±0.5%/1%，只动低显著性块，时间平滑 |
| C3 | 色度微扰 | Cb/Cr ±2/4/6/255，全局与低频两种 |
| C4 | 中频 DCT 扰动（midband 参数化） | 强度 0.2/0.4/0.6 |
| C5 | 文字感知选边 | 对比度检测四边文字带，只裁干净边 2%/3% |

## 4. 数据与流程

- 素材：现有 4 个 12s 真实片段（疑似暗水印 x3 + 干净视频 x1，540x960）+ 1 个 60s
  片段用于效率测量。
- 配置：固定 seed 7。
  - 配置 A"仅重构"：decode -> candidate -> encode，用于消融对抗/观感。
  - 配置 B"完整平衡档"：reorder + speed 0.955 + regrade + candidate 替代 recrop，
    只对配置 A 通过者运行。
- 两阶段：
  1. 配置 A 在 4 片段 x 全部候选上出哈希矩阵 + VMAF + 边缘带指标；
  2. 通过者跑配置 B（1~2 片段）并在 clip60 上测端到端耗时。

## 5. 产出物

- 候选 x 指标矩阵表（四族哈希距离、duplicate_risk、VMAF、边缘带标记、耗时、过门
  标记、原生下沉备注）；
- 通过者的逐帧对比图（原片 | 旧 recrop | 候选）；
- 一句话结论与推荐，或"全不达标 -> 保留旧 recrop"。

## 6. 假设与边界

- 代理判重栈阈值未对标真实平台，结论只表示相对旧 recrop 的强弱，不承诺平台通过率。
- 平台终验依赖反馈留档，留档建设属于后续方案 B，不在本摸底范围。
- 候选在变换层实现并计时；原生下沉可行性仅作备注，不在本摸底实现。
- 摸底脚本为一次性产物，不进入产品代码库。
