# 研究笔记：盲检测基线 v1（M2 第一步）

> **研究用途声明**：本文仅用于数字水印、内容指纹、媒体取证与视频变换的研究、教学和授权测试；严禁用于规避平台规则、去除版权/溯源水印、侵权搬运、账号矩阵规避或其他违法违规用途。完整边界见项目根目录 `docs/研究用途与合规声明.md`。

> 状态：已实现并复现基线数据。所有数字为研究口径启发式结果，不替代平台实测。

## 1. 实现内容

- `watermark/detect.py`：四个无先验盲检测器，输出 0~1 置信度。
  - `ss_blind`：空域扩频协同平均（多帧残差均值能量比）。
  - `qim_blind`：DCT 中频系数到量化格点的距离集中度（扫描 delta 4/6/8）。
  - `lsb_blind`：χ² PoV 位平面统计。
  - `echo_blind`：回声延迟窗口（40~200 样本）倒谱峰异常。
- `evaluate/harness.py` 新增检测评估闭环：干净基线 → 水印 → 各攻击后置信度对比。
- CLI 新增 `cthulhu detect-watermark <file>` 与 `cthulhu detect-harness`。

## 2. 合成样本基线（320×240，16 帧，seed=0，64bit payload）

| 方案 | 干净基线 | 水印样本 | 说明 |
| :--- | :--- | :--- | :--- |
| QIM | 0.220 | 0.987 | 强可检，区分度 0.77 |
| SS | 0.510 | 0.672 | 弱可检，区分度 0.16，待改进 |
| LSB | 0.287 | 0.287 | 不可盲检（见结论） |
| echo（音频） | 0.525 | 0.649 | 弱可检，区分度 0.12 |

## 3. 攻击后残留可检性（QIM）

| 攻击 | 置信度 | 解读 |
| :--- | :--- | :--- |
| 水印 | 0.987 | 基准 |
| 重量化 requant | 0.235 | 检不出，清除有效 |
| 几何 crop/rotate/rescale | 0.293 | 检不出，清除有效 |
| 中值滤波 | 0.344 | 大幅削弱 |
| Wiener | 0.832 | 仍可检出 |
| 时序 drop/dup | 0.987 | 不受影响 |

## 4. 研究结论

1. DCT-QIM 是当前可检测性最强、也最值得作为主攻方向的方案；重量化与几何
   变换是有效的清除手段，Wiener/时序攻击对其无效。
2. 空域扩频在单帧/多帧协同下仅有弱区分度，检测器需要迭代（方向：残差
   功率谱平坦度、跨帧相位对齐后协同）。
3. **低负载「直接写位」LSB 在数学上不可盲检**：替换 5% 随机位后的位平面
   仍是随机。χ² PoV 针对的是顺序替换嵌入，对本基准覆盖型嵌入无效。
4. **有损压缩是像素域检测器的强污染源**：H.264 量化破坏 LSB 随机性，
   `lsb_blind` 对压缩视频恒定误报（实测演示库干净视频得分 1.0）；QIM 基线
   也从 0.22 抬升至 0.60。因此真实检测必须「解码像素域 + 压缩域联合 + 与
   干净同源基准差分判定」，单样本绝对分数不可直接用于判定。

## 5. 下一步

- 把盲检测分数接入 GUI 检测报告的「多方案命中」维度（附差分基准）。
- 迭代 SS 检测器（功率谱平坦度 / 协同相位对齐）。
- 建立真实压缩样本的差分基线库，标定各检测器的压缩域阈值。
- 用检测置信度下降幅度作为清洗强度的量化验收指标。

## 6. 压缩域差分基线（v2，2026-08-20）

新增 `evaluate/harness.run_compressed_detection_baseline` 与
`cthulhu detect-baseline`：所有样本经 H.264（crf 23）编码往返后检测，
复现 3 seeds 基线如下（320×240，12 帧，64bit payload）：

| 方案 | 干净 | 水印 | 差分 | 结论 |
| :--- | :--- | :--- | :--- | :--- |
| SS | 0.514±0.000 | 0.631±0.003 | +0.117 | 压缩后仍可检，是链路残存方案 |
| QIM | 0.637±0.025 | 0.354±0.014 | -0.283 | 格结构被量化摧毁，不可检 |
| LSB | 1.000±0.000 | 1.000±0.000 | 0.000 | 无生存力且恒定误报 |

### 策略影响

1. **像素域结论不可外推**：QIM 在未压缩域最强（0.99），但一次普通压缩即
   摧毁，方向反转；LSB 完全无生存力。研究目标应从「像素域可检」转向
   「压缩链路可检」。
2. **SS 应升级为研究主攻方案**：低强度加性扩频在编码后仍有 +0.117 的稳定
   差分。下一步需提高区分度并做多帧协同。
3. **检测判定必须差分化**：压缩后各方案基线各不相同（SS 0.51 / QIM 0.64 /
   LSB 1.0），不存在通用绝对阈值。任何单样本分数都不能直接用于判定，
   「干净同源基准差分」是唯一可靠框架（bitstream `--reference` 同理）。
4. 清洗验收指标的候选定义：处理后「含水印样本与干净基线的差分」应回落到
   干净噪声水平（SS 差分 → 接近 0），可作为多期清洗强度的量化验收。

## 7. SS 检测器迭代（v3）

原 `ss_blind` 的能量比特征本身区分度达 30 倍（干净 0.067 vs 水印 2.0），
但 sigmoid 标定过宽把差异压成 0.15 分。重新标定后：

| 域 | 干净 | 水印 | 差分 |
| :--- | :--- | :--- | :--- |
| 像素域 | 0.266 | 0.938 | +0.672 |
| 压缩域（crf23） | 0.285 | 0.870 | +0.585 |

结论：
- 谱平坦度特征无效（干净与含水印残差谱平坦度均为 -3dB 左右），放弃。
- 时间均值能量比（协同平均）是 SS 的核心检测信号，校准后压缩域差分从
  +0.117 提升到 +0.585，SS 成为压缩链路上与 QIM 同级的可检方案。
- 测试断言已同步收紧（像素域 margin 0.4、压缩域差分 0.3），防止回归。

## 8. 清洗强度量化验收（v4）

基线函数新增 `residual_ratio`（处理后差分 / 水印差分，越低清除越彻底）：

| 攻击 | SS 残留比 | 解读 |
| :--- | :--- | :--- |
| gaussian | 0.037 | 清除 96% |
| median | 0.051 | 清除 95% |
| wiener | 0.073 | 清除 93% |
| geometric | 0.132 | 清除 87% |
| requant（重量化） | 0.955 | 几乎无效 |

### GUI 清洗管线实测（SS 水印，crf23 编码后）

| 清洗配置 | SS 分数 | 说明 |
| :--- | :--- | :--- |
| 干净基线 | 0.28 | — |
| 水印（编码后） | 0.75 | — |
| 平衡档现状（重排+调光+微扰 0.2+锐化+色彩还原） | 0.42 | 清除约 70% |
| 平衡档 + Wiener 空间降噪 | 0.31 | 清除约 95% |

### 决策与结论

1. **空域扩频怕空间滤波、不怕重量化**；QIM 恰好相反（怕重量化）。
   真实清洗应组合「去噪 + 重量化」两类手段，覆盖互补盲区。
2. GUI 清洗管线此前缺少去噪环节，对 SS 清除不彻底；已将 Wiener
   空间降噪默认开启，并修正「AI 降噪」这一名不副实的文案。
3. 验收指标确立：以「处理后 SS 差分回落至干净噪声水平」作为清除强度
   的量化标准，写入后续多期验收流程。

## 9. 清除盲区评估（v5）

### 重量化重编码：暂缓接入

实验（QIM delta 6/10/16 × crf23 编码往返）显示：所有强度的 QIM 在普通
H.264 压缩后均已被摧毁（分数低于干净基线），像素重量化没有增量收益。
强行加入只会变成「选了没反应」的假参数，故暂缓；待引入更高鲁棒性的
基准方案后再评估。

### BM3D 去噪：暂缓接入

Wiener/中值滤波对 SS 的清除率已达 93%~96%，BM3D 增量有限且需要引入
重依赖（opencv 或专用包），投入产出比不足，暂缓。

### 音频回声清除：已校准

GUI 默认的音频重混变速系数 0.99 对回声水印清除不彻底（分数 0.649→0.573），
实测 0.97 可回落到干净基线（0.520）。已将默认值校准为 0.97，并同步
对齐音画时长。这是音频侧的第一项量化验收。

## 10. 盲检测族扩编与真实样本标定（v6，2026-08-27）

检测族从 ss/qim/lsb/echo 扩到 8 个像素域检测器：新增 `temporal`
（帧差能量噪声化度）、`dwt`（Haar HH 子带能量比）、`chroma`（色差残差/
亮度残差比，需彩色解码）、`dctmod`（DCT 模运算格点，逐系数位置独立统计）、
`svd`（4×4 块前导奇异值格点）。同时输出逐窗口一致性**置信度**，并把 qim
改为一次 DCT 三个 delta 共用（约 3 倍提速）。全部数字见
`docs/baselines/detect-calibration.json`。

| 检测器 | 干净 | 水印 | 建议阈值 | 区分度 | 结论 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| ss | 0.234 | 0.935 | 0.58 | 0.70 | 强 |
| qim | 0.221 | 0.985 | 0.60 | 0.76 | 强 |
| temporal | 0.274 | 0.787 | 0.53 | 0.51 | 强 |
| dwt | 0.460 | 0.876 | 0.67 | 0.42 | 可用（干净基线偏高） |
| dctmod | 0.137 | 0.743 | 0.44 | 0.61 | 强 |
| chroma | 0.159 | 1.000 | 0.58 | 0.84 | 强 |
| svd | 0.157 | 0.319 | 0.24 | 0.16 | **弱信号，仅作辅助** |

### 真实巨量样本带（3 被拦 + 5 通过，2026-08-27 平台对照）

| 检测器 | 被拦范围 | 通过范围 | 分离 margin |
| :--- | :--- | :--- | :--- |
| ss | 0.863~0.992 | 0.624~0.993 | -0.13 |
| qim | 0.785~0.855 | 0.785~0.893 | -0.11 |
| temporal | 0.738~0.879 | 0.727~0.881 | -0.14 |
| dwt | 0.387~0.391 | 0.373~0.391 | 0.00 |
| chroma | 0.290~0.707 | 0.279~0.470 | -0.18 |
| dctmod / svd | 0.14 / 0.18 | 0.14 / 0.20 | ~0 |

（2026-08-27 性能优化后重新实测：统计类检测器降到 640 长边计算域，
结构类保持原始分辨率。分离 margin 仍全部 ≤0，结论不变。）

**结论（与平台对照实验互证）：任何像素域检测器都无法区分巨量的「被标记 /
通过」样本**——仅重封装、仅重编码的通过样本与原版的分数完全重叠。这从检测
侧再次确认：巨量的「暗水印」判据在文件字节身份层，不在媒体内容里，本地
像素/码流检测对它**原理上不可复现**。ss 高分的真实来源是 AI 生成视频的
静态纹理特征，而非平台水印；必须避免把 ss 高分解读为「平台会判重」。

### 判定口径（v6 起）

单样本绝对分数仍不可直接判定，报告必须给三要素：**分数 + 窗口置信度 +
与干净同源基准的差分**。svd 只作辅助信号；lsb 对压缩视频恒定误报，仅作
提示。巨量类「文件身份」判定本地不可覆盖，需在报告口径中明示。

### 检测性能（2026-08-27 实测，322s 720p 素材）

| 阶段 | 优化前 | 优化后 |
| :--- | :--- | :--- |
| 全流程 | 29.8s | **4.5s** |
| 其中窗口盲检测（原 ss 中值滤波占 21.5s） | 25.5s | 2.4s 级 |

优化项：① 统计类检测器（ss/temporal/dwt/chroma）降到 640 长边 float32 计算域；
② qim/lsb 收敛到全分辨率 90 帧、每窗口 15 帧；③ 窗口并行（scipy 滤波释放
GIL）；④ 色度解码直接由 ffmpeg 等比降采样。结构类检测器（qim/dctmod/svd）
保持原始分辨率以保证灵敏度；阈值未变（合成标定域 64×64 不受影响）。

### 判定口径（v7，2026-08-31，取代 v6 的"三要素"地位）

2026-08-31 用真实原片（AD-下载8 原片 vs 清洗版 vs 纯转码 A0 vs 强力/全兵器
再清洗）复核后，对判定口径做两点硬性修订：

1. **本地像素域检测器（含 ss/qim/dctmod/svd/dwt/chroma/temporal/echo）一律
   降级为内部回归工具**，只用于防止清洗参数回退，不再承担"是否通过暗水印
   检测"的判定。理由：a) 原片与 A0 纯转码分数几乎逐位一致，说明分数是
   「内容 + 编码」的确定性函数；b) 清洗在自己检测器上有效（ss 0.86→0.62、
   chroma 0.71→0.47）但平台依旧判"有暗水印"，说明平台判据与本地检测器正交；
   c) 加强度（强力/全兵器）反而推高 ss/temporal（0.62→0.69/0.77），说明
   "对抗武器越猛、自己检测器越报"。
2. **平台相关反馈只能在授权测试环境中观察，不能被视为本地研究结论之外的
   唯一裁判**。本地任何分数（包括差分、码流层）都只是研究信号，不允许进入
   对用户的承诺口径。历史测试记录见
   [平台黑盒实验-决策树.md](平台黑盒实验-决策树.md)（现已收窄为合规边界说明）。

同期冻结两条研究线："定位真实暗水印所在"与"继续提高清洗强度"。理由：平台
级暗水印是带密钥的全帧神经水印（见字节跳动安全中心《隐秘的印记：暗水印
实践技术分享》，2021），无密钥原理上不可盲检、不可定位，本地无法验证攻击
效果，继续投入没有可观测的收敛判据。
