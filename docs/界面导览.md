## 2. 任务中心

<p align="center">
  <img src="assets/screenshots/ui-jobs.webp" alt="任务中心：队列状态统计与任务历史列表" width="880">
  <br>
  <sub>任务中心：排队 / 处理中 / 已完成 / 失败统计，任务历史含耗时、输出路径与所用管线</sub>
</p>

- 批量任务统一入队，按设置的并行度调度，支持优先级、暂停、继续、取消、失败重试与历史清理；
- 每条任务记录素材名、创建时间、耗时、输出路径与管线档位，可直接打开产物所在目录；
- 进程重启后按记录自动续跑未完成任务，避免整批实验因中断作废。

## 3. 去重模板

<p align="center">
  <img src="assets/screenshots/ui-templates.webp" alt="去重模板管理：内置预设与各项参数概览" width="880">
  <br>
  <sub>去重模板：内置四档预设（画质优先 / 平衡去水印 / 强力去水印 / 深度清剿），可新建、编辑、复制与删除</sub>
</p>

模板把一次去重用到的参数组合固化为可复用对象，卡片上直接展示经典指纹、空间降噪
与音频重混、重编码与信号扰动、暗水印处理与嵌入域、输出编码等分组下的启用项数，
便于在复用前快速核对强度与代价。

## 4. 产物管理

<p align="center">
  <img src="assets/screenshots/ui-products.webp" alt="产物管理：产物总数、占用空间与产物清单" width="880">
  <br>
  <sub>产物管理：集中查看产物数量、占用空间、来源素材与生成时间，并支持批量清理</sub>
</p>

产物按时间倒序排列，可直接打开或删除；「文件缺失」计数用于提示被外部移动或删除
的产物，避免实验记录与磁盘内容不一致。

## 复现与更新截图

1. 使用 `pnpm dev:desktop` 启动当前桌面版。
2. 导入一段自有或已获授权的真实视频；需要产物截图时，先完成一次短片段去重。
3. 依次打开工作台、任务中心、去重模板、产物管理和设置，等待页面数据加载完成。
4. 工作台分别截取浅色与深色主题，其余页面使用浅色主题。
5. 输出宽度为 1512 像素，保存为 WebP，文件命名 `ui-<视图>.webp`，存放于
   `docs/assets/screenshots/`。
6. 更新前检查画面；素材名称或输出路径包含个人信息时，先对路径区域做模糊处理。
