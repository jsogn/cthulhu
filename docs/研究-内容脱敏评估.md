# 研究笔记：内容脱敏评估 v1

> **研究用途声明**：本文仅用于数字水印、内容指纹、媒体取证与视频变换的研究、教学和授权测试；严禁用于规避平台规则、去除版权/溯源水印、侵权搬运、账号矩阵规避或其他违法违规用途。完整边界见项目根目录 `docs/研究用途与合规声明.md`。

> 状态：第一轮消融完成。新增 CLI：`cthulhu desensitize-matrix`。

## 1. 背景与目标

研究性变换是项目的一级实验功能，但「各参数对内容指纹代理指标的实际影响」
此前未被量化。本轮建立评估闭环：对带硬切镜头的合成样本，跑三档实验与单变量
消融，输出内容相似度、运动相似度、时序乱序度与 PSNR。

## 2. 指标口径

- `content_cosine` / `motion_cosine`：自建 embedding 的语义与运动统计相似度。
- `order_disruption`（新增）：重排序列逐帧映射回原始最近帧后，相邻映射
  跳变的比例。乱序重组的破坏效果由此量化——原顺序为 0，重排后升高。
- `psnr_db`：**未时间对齐的帧序差**，重排/变速场景下因帧错位被严重拉低，
  仅作同口径横向对比，不代表逐帧视觉画质。

## 3. 消融结论（8 段×10 帧硬切样本）

| 配置 | content | motion | 乱序度 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 仅重排 | 1.0000 | 0.250 | 0.076 | 时序指纹破坏主来源 |
| 仅变速 | 0.9996 | 0.928 | 0.000 | 对顺序无破坏 |
| 仅裁剪 | 0.9993 | 0.979 | 0.089 | 轻微乱序（裁切匹配错位） |
| 仅调光 | 1.0000 | 0.970 | 0.000 | 画质代价最低 |
| 深度档 | 0.9985 | 0.326 | 0.131 | 组合破坏最强 |

结论：
1. 乱序重组对时序代理指标影响最大，语义内容保持 0.998+，符合研究目标中
   「内容可用、代理指标变化可测量」的定位。
2. `motion_cosine` 不度量顺序，不能单独作为乱序重组的验收指标；
   `order_disruption` 补上了这一缺口。
3. 调光/裁剪/变速对内容语义几乎无影响，主要贡献画质扰动与运动统计改变。

## 4. 顺带修复

前端清洗参数中 `perturb` 档位此前未传入后端（只传了由它派生的 recrop），
导致重调光强度恒为最低档。已接线：三档现在真正改变调光与微扰强度。

## 6. 时间对齐画质口径（v2）

帧序 PSNR 在重排/变速下因帧错位失真（三档曾测得 7dB 的荒谬值），
新增 `temporal_aligned_psnr`：处理帧逐帧匹配原始最近帧后计算，
度量「每帧内容的视觉保真度」。复测（6 段×10 帧硬切样本）：

| 配置 | 对齐 PSNR | 解读 |
| :--- | :--- | :--- |
| 仅重排 | ∞ | 帧内容不变，画质无损 |
| 仅变速 | ∞ | 插值帧与最近帧几乎一致 |
| 仅裁剪 | 25.3 dB | 缩放是主要画质损失来源 |
| 仅调光 | 38.6 dB | 高保真 |
| 轻度/平衡/深度 | 25.7 / 25.0 / 23.3 dB | 强度梯度合理 |

结论：对齐口径消除了时间错位污染，三档呈现单调的画质代价梯度；
裁剪（recrop）是当前参数链中画质损失最大的单项。
