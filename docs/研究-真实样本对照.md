## 3. 初步结论（n=1，仅线索）

1. SS 与 echo 在疑似样本上更高、方向一致，是当前最值得继续验证的信号；
   需要多对同源对照做统计检验。
2. QIM 无区分度。
3. 压缩域绝对阈值方向相反（干净反而 50 分），再次确认不可作为判定依据，
   与「同源差分」路线一致。
