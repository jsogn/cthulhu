## 2. 产品定位与目标

- 本地端专业视频暗水印检测与清理桌面软件，面向普通运营/剪辑人员，零算法门槛。
- 私有分发：不对外公开，不做账号体系/联网服务；核心功能全程本地离线。
- 对齐 PRD 目标（以对照实验逐步校准，不直接承诺）：
  - 功能：覆盖 LSB/DCT/DWT/帧间/音频等主流暗水印类型。
  - 性能：1080P 处理目标 1:1.5，批量并发队列。
  - 画质：PSNR≥40dB，人眼无感知损失。
  - 业务：面向短剧投流、矩阵运营、二创分发的批量处理工作流。

## 3. 技术选型与桌面架构

### 3.1 语言结论

- **核心全部用 Python 3.12+**：算法、媒体处理、任务调度、数据库、导出、审计。
- 重计算下沉原生库：FFmpeg（编解码）、OpenCV（帧处理/inpainting）、NumPy/SciPy/pywt（DCT/DWT/统计）、ONNX Runtime（LaMa）。
- Rust 例外路径：仅某个内核 Python 无法满足时以 PyO3 编写扩展，不预先依赖。

### 3.2 桌面壳：Electron（已定稿）

评估结论：pywebview 轻量但不足以满足"macOS 优先 + 完美可用"——

- macOS 走 WKWebView，与 Windows 的 WebView2 不是同一引擎，渲染表现存在平台差异；
- 拖拽导入是核心交互，pywebview 的 macOS 拖拽处理 2026-04 才修复（PR #1742），且 Web 层拖放只能拿到文件名，完整路径需绕原生桥；
- 多窗口、无边框窗口、DevTools 能力均弱于 Electron。

因此采用 Electron 方案，换取两端一致的 Chromium 内核、一等公民的拖拽与 DevTools、成熟的 macOS 打包链（electron-builder → dmg）。代价是包体约 150MB、多一个 Node 运行时，私有分发场景可接受。

## 4. 界面与交互设计（对齐 M2 原型）

- 单窗口多视图，侧边导航：工作台 / 任务中心 / 模板 / 历史 / 设置。
- 工作台三栏：左素材库（导入、批量扫描、筛选/标签、来源登记、批量操作），中预览（播放/拖帧/对比滑杆/框选画布），右上下文面板（检测报告 / 水印区域 / 合规清洗 / 导出设置）。
- 双主题：暗黑/浅色，默认跟随系统；中文系统字体栈 + 等宽时间码。
- 任务状态机：`idle → scanning → detecting → reviewing → processing(x%) → exporting → done | error`。
- 交互规则：可点击目标 ≥44px、键盘可聚焦、焦点环、对比度 ≥4.5:1、批量操作可暂停/恢复/取消。
- HTML 原型迁入 React 工程，作为视觉与验收基线。

## 5. 功能范围

### 5.1 MVP（V1.0）

- 素材库：文件/文件夹导入、元信息解析、去重、格式校验、搜索/筛选/标签、来源登记。
- 样本采集与制备（研发侧）：干净/带水印样本对、帧对齐、差分、元数据登记，支撑检测与清除的对照实验。
- 可见水印修复：自动候选区域 + 手动框选（多区域、时间范围），FFmpeg delogo / OpenCV TELEA / NS。
- 暗水印检测：元数据/SEI、频域 DCT/QIM 指纹、音频指纹、内容指纹提示四维度，输出风险等级、命中维度、频域热区、推荐档位。
- 暗水印清除（三层）：基础层系数收缩、进阶层量化域偏移+块相位扰动、高阶层伪水印注入+二次嵌入免疫；三档强度。
- 对抗增强：GOP 随机化、QP 帧间波动、行相位偏移、多维度特征混淆，逐项开关与强度参数化。
- 批量队列：状态机、并发可配、优先级、暂停/恢复/取消/重试、失败隔离、断点续传。
- 自带校验：处理完自动二次扫描 + BER/PSNR/SSIM + 前后对比。
- 模板、审计日志、导出、设置、双主题。

## 6. 核心引擎设计（Python）

### 6.1 样本采集与制备

- 同一素材在目标平台上传前后的配对采集，控制变量（账号/设备/分辨率/版本）登记。
- 亚像素帧对齐与预处理，差分仅保留水印贡献；样本元数据入库。

### 6.2 检测引擎

- 空域 LSB、频域 DCT/QIM 指纹、小波 DWT、帧间时序、音频指纹、盲检测兜底（PRD 5.2 阈值作初值，对照实验校准）。
- 输出结构化报告 + 频域热区。

### 6.3 清除引擎（三层）

- 基础层：`c' = floor(c/Q)*Q + Q/2`，Zigzag 12~35 位，区域自适应，块边界平滑。
- 进阶层：量化基准 ±1 偏移、中频 ±0.5Q 高斯加噪、亚像素块相位偏移、周期性亮度微偏移帧。
- 高阶层：伪水印注入（原始强度 60%）、GOP 随机化、行相位循环偏移。
- 画质保底：引导滤波、USM 锐化、色彩校正，JND 分级约束。

### 6.4 对抗模块

- 抗二次嵌入：中频随机扰动、GOP 25~35 帧随机化、QP ±1 波动、禁用自适应量化、输出码率高 10%。
- 特征混淆：亮度/色度微偏移、几何微形变；逐项开关与强度参数化，支持消融对照。

### 6.5 评估/校验模块

- 简化版平台水印提取器计算处理前后 BER：>80% 判有效、>95% 判完全清除。
- PSNR/SSIM、鲁棒性测试（二次压缩/裁剪/缩放/旋转/抽帧）、吞吐与内存。

### 6.6 编解码与调度（PRD 5.5）

- 解码硬件优先，YUV420P 全程原生，最大 4096×2160。
- 编码 libx264，CRF 三档 23/24/25，音频 AAC 128kbps 优先原样复制。
- 并发：CPU = 物理核/2（上限 8）；FIFO + 优先级抢占；每 10 帧写快照断点续传。

## 9. 验收标准（产品 + 算法双轨）

产品轨：

- 主流程可点通：导入 → 框选 → 对比 → 导出；检测流程：导入 → 扫描 → 报告 → 清除建议。
- 批量导入 20+ 素材流畅，去重与格式校验可见；模板一键应用整批；单条失败不影响整批且可重试。
- 导出目录/命名正确，汇总报告与审计日志完整；任务状态可见反馈，无死按钮。
- 双主题对比度达标；三栏布局 1280–1920px 稳定；macOS 拖拽导入可用。

算法轨：

- 检测与样本真实标签的命中率/误报率可量化；三层清除分别给出 BER、PSNR/SSIM、吞吐分布。
- 鲁棒性与对抗模块消融实验有数据。
