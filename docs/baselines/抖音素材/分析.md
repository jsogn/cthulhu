# 抖音下载素材检测分析（2026-08-24）

> **研究用途声明**：本文仅用于数字水印、内容指纹、媒体取证与视频变换的研究、教学和授权测试；严禁用于规避平台规则、去除版权/溯源水印、侵权搬运、账号矩阵规避或其他违法违规用途。完整边界见项目根目录 `docs/研究用途与合规声明.md`。

> 样本：用户提供的三支抖音平台下载视频，高度疑似携带暗水印。
> 方法：生产检测管线（容器/元数据/SEI + 码流层 + 盲检测抽样 + 音频回声）。
> 口径：单样本启发式结果，仅作相对参考；判定需干净同源基准差分（见《研究-盲检测基线》）。

## 2. 逐项解读

### 容器与元数据

- 三支视频均为 H.264 + yuv420p，双音视频轨；`udta`/`meta` 各 1 个，无 XMP。
- 无可疑 box，SEI 计数为 0。未发现容器层的明显溯源标记。

### 码流层

- 0608：QP 均值 22.5、标准差仅 1.46，GOP 250 帧（约 8.3 秒一个关键帧）。编码
  质量高、QP 波动小，更像成片导出后未再重度转码。
- 0702：QP 周期性 0.77、码量周期性 0.66，GOP 96，评分中。周期性可能是内容
  节奏或固定量化策略，也可能是嵌入带来的规律，**无干净同源基准时无法归因**。
- 0717：仅码量周期性 0.59，QP 周期弱，整体低。

### 盲检测（像素域）

- LSB 三支全部 1.0：有损压缩视频的恒定误报，**不采信**（与合成基线结论一致）。
- 0608 的 SS=0.98、QIM=0.94 明显高于压缩域干净基线（SS≈0.28、QIM≈0.64），
  是最值得注意的一支；但也可能来自该片高锐度、慢节奏与轻压缩。
- 0702/0717 的 SS 在 0.57~0.68，处于内容可解释区间，不构成独立证据。
- 回声分数 0.66~0.70，略高于基线但区分度低，仅作弱信号。

## 3. 结论

1. **无法仅凭这三支单样本断定“存在暗水印”**：没有同源干净对照，任何单项分数
   都可能由内容与转码造成，符合项目“检测必须差分化”的方法论。
2. 存在三个值得深挖的异常：0608 的 SS/QIM 双高 + 长 GOP 轻压缩；0702 的
   QP 与码量双周期性。平台真实水印若存在，最可能隐藏在这类规律中。
3. 下一步判定路径：取得同源配对样本（上传前原片 vs 下载片）做差分；或对这三支
   执行变换实验后复检，观察周期性指标与盲检测分数是否显著回落。

## 4. 同源差分复核（原版 vs 下载版）

用户补充了三支对应原版（1080×1920，5~8 Mbps）。结论发生关键修正：

### 盲检测差分

| 样本 | 原版 SS / QIM / 回声 | 下载版 SS / QIM / 回声 | 解读 |
| :--- | :--- | :--- | :--- |
| 0608 | 0.984 / 0.936 / 0.681 | 0.982 / 0.939 / 0.689 | 几乎一致，高分来自内容本身 |
| 0702 | 0.596 / 0.779 / 0.635 | 0.574 / 0.691 / 0.657 | 无明显抬升 |
| 0717 | 0.623 / 0.603 / 0.687 | 0.675 / 0.531 / 0.700 | 互有高低，无一致抬升 |

此前单样本的 SS/QIM 高分被证伪：原版同样高分，属于内容与导出编码特征，不是
平台嵌入水印的信号。

### 码流差分（下载版 --reference 原版）

| 样本 | 差分评分 | dQP 周期性 | d码量周期性 | 关键事实 |
| :--- | :--- | :--- | :--- | :--- |
| 0608 | 0（低） | -0.36 | -0.12 | GOP 同为 250，无新增周期 |
| 0702 | 40（中） | -0.33 | +0.33 | GOP 30→96，720p 降采样 |
| 0717 | 40（中） | -0.33 | +0.27 | GOP 30→109，720p 降采样 |

0702/0717 的「码量周期性高于基准」与平台把 GOP 从 30 改为 96/109、并降采样到
720p 的常规转码行为完全吻合；QP 周期性反而普遍下降，不存在“下载后新增 QP 规律”。

## 5. 最终结论

1. **未检出能归因于暗水印的特征**：容器干净（无 XMP/异常 box/SEI），像素域
   分数与同源原版一致，码流差分只体现了平台转码（改 GOP、降采样），没有
   “下载后新增周期性”的证据。
2. 早前单样本阶段的“高度疑似”判断被差分复核否定，说明检测必须坚持同源差分，
   单样本高分不可信。
3. 局限：本工具为启发式检测器，若抖音使用 DCT 具体系数、帧间相位等专属方案，
   当前仪器可能覆盖不到。进一步验证只能在获得明确授权的测试环境或学术合作
   渠道中进行，不得通过重新投流或规避平台规则来验证。

结论：四个探测域均未发现“下载版相对原版新增的结构化信号”。0702/0717 的
DCT 能量差异与降采样丢失细节一致（差异空间分布与内容相关度 0.95+），逐系数
残差除 DC 亮度偏移外全部是噪声。若平台在这三支文件里嵌入了水印，它要么
强度低于我们的噪声底，要么使用了本工具未覆盖的域；目前无法给出“有”的证据。
