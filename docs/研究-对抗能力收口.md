# 研究第一阶段收口：对抗能力清单与边界

> 2026-08-21。目标：把「无样本条件下可完成的研究」正式收口，明确
> 已具备、未实现、未决项与下一步依赖，防止继续无样本堆砌低价值武器。

## 一、已具备（按威胁域）

- 几何：旋转（黄金角摆动）、裁剪回缩、平移抖动、水平镜像、透视剪切、局部平滑扭曲
- 空域：高斯噪声、中值、Wiener 去噪、锐化、像素重量化、调光/色彩还原
- 频域：DCT 中频扰动、DCT 系数重量化
- 色度：色度量化
- 时域：分镜乱序、变速、抽帧复制
- 编码域：参数化重编码（codec/preset/CRF/GOP）、跨 codec 转码链
- 签名域：pHash 对抗求解、pHash/aHash/dHash/DCT 符号联合求解
- 估计类：Wiener 残差盲估计相减
- 内容层：边框、角标、字幕条、局部马赛克（两档显著性）
- 音频：变速重混
- 伪装：伪水印注入、中频抗二次嵌入

配套基础设施：平台代理评估套件（哈希/边缘/关键点/音频谱）、检测基准
A/B 工具、策略化切换与任务归因、彩色全链路、性能优化（流式解码、uint8
端到端、求解向量化、解码预取）、五档 UI 预设、CI 打包。

## 二、未实现（明确为低价值或需外部条件）

- 小波域收缩/重量化：覆盖面，低优先
- 音频高质量变调/相位置乱/频带重排：中等价值，待测试反馈触发
- 多副本协同平均、成对样本差分：需平台样本
- 生成级重绘：待 AI 代理证明现有兵器对神经网络 embedding 无效后再投入

## 三、已知未决问题

1. 平台真实暗水印方案未知（嵌入域/强度/冗余/加密）。
2. 深度 embedding 层的真实鲁棒性未知——手工代理（边缘/关键点）低估
   CNN 的不变性，需预训练视觉模型代理补盲。
3. 「通杀」在无平台 oracle 下不可证明；第二阶段必须黑盒验证。
4. 新增证据：CLIP ViT-B/32 代理实测，全兵器组合（含联合求解与显著性）
   只能把 deep_cosine 从 1.0 压到 0.933——embedding 层确认无便宜解法。
   手工代理此前高估了破坏力，AI 代理成为标准裁判。

## 四、结论

第一阶段（通用兵器 + 本地代理）宣告收口；继续无样本堆砌原语边际价值低。
第二阶段（黑盒判重、成对样本差分、方案识别与针对性攻击）依赖真实素材，
代码无法替代。收口后的两条主线：AI 代理升级（测量盲区），等待判重素材。
