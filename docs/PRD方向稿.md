## 1. 项目目的

Cthulhu 是研究型实验项目，目的是帮助研究者、学生和工程实践者理解：

- 数字水印与内容指纹的嵌入、检测、提取和鲁棒性边界；
- 视频编码、几何变换、时域处理、音频处理对媒体特征和画质的影响；
- 本地代理指标、差分分析、误码率、相似度与画质指标的研究方法；
- 如何用合成样本、自有素材或已授权素材构建可复现、可审计的实验。

本项目不提供平台审核通过、流量提升、账号安全、内容分发效果或商业收益承诺。

## 2. 允许的研究问题

1. 公开或自建水印方案的嵌入/检测算法与鲁棒性分析；
2. 内容感知哈希、内容指纹和相似度代理指标的行为与局限；
3. 视频编码、重采样、几何变换、时域处理和音频处理对媒体特征的影响；
4. 画质指标、差分分析、误码率和代理评分等评估方法的校准；
5. 在获得明确授权的测试账号、测试接口或沙箱环境中，进行平台规则合规性观察；
6. 将上述方法用于课程教学、论文复现、公开数据集实验和算法工程实践。

## 3. 明确禁止的用途

- 去除、破坏或伪造版权水印、所有权标识、来源标识、取证水印或依法应保留的标识；
- 规避、绕过或对抗平台的内容审核、版权识别、重复内容识别、风控或账号治理规则；
- 侵权搬运、盗版传播、未经授权的内容二次分发或冒充原创；
- 账号矩阵规避、批量规避关联处罚、刷量、欺诈或其他不正当运营行为；
- 侵犯他人隐私、肖像权、名誉权、知识产权或其他合法权益；
- 违反适用法律法规、平台服务条款、行业规范或所在机构政策的行为；
- 将研究结果包装为“保证过审”“保证不限流”“保证不被识别”等承诺并对外传播。

## 4. 研究输出与解释边界

- 本地检测分数、代理指标、BER、PSNR、SSIM、VMAF 等结果只代表特定实验条件下
  的可复现测量，不代表平台真实判定；
- “基准库内有效”不等于“真实平台有效”；
- 平台反馈只能在授权范围内解释，不得用于规避平台规则；
- 所有结论应如实标注样本来源、授权范围、参数、随机性、失败案例和未知边界；
- 研究结果不得用于商业宣传、平台规避服务或任何违法违规用途。

## 5. 历史材料处理

仓库中的 `docs/研究-*.md`、`docs/平台黑盒*.md` 和 `docs/baselines/` 保留为
历史研究记录。其中出现的“清洗”“去重”“攻击”“通杀”“投流”“逃逸”等词，
仅用于描述研究环境中的变换处理、鲁棒性压力测试、相似度度量和代理指标变化，
不构成操作指导，也不代表允许规避平台规则。

任何历史文档与本文件或 [研究用途与合规声明](研究用途与合规声明.md) 冲突时，
以后者为准。

1. 新增功能说明必须使用“变换实验”“鲁棒性评估”“相似度分析”等中性表述；
2. 不得新增面向真实平台的规避步骤、投放规避话术或“保证通过”承诺；
3. 涉及平台测试的文档必须写明“仅限授权测试账号/沙箱环境，不得用于规避平台规则”；
4. 发现违规用途或高风险用法时，应停止相关使用并报告维护者；
5. 所有实验应优先使用合成样本、自有素材或已获明确授权的素材与测试账号。
