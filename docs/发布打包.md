## 1. 应用图标

- 已生成 `packaging/icons/icon.png`（1024）与 `icon.ico`（多尺寸），electron-builder 已配置。
- 运行 `uv run --project backend python packaging/make_icon.py` 可重新生成。

- 机制已就绪：`CTHULHU_FFMPEG_DIR` 环境变量解析（后端）、Electron 生产环境自动指向 `resources/ffmpeg`、`packaging/ffmpeg` 资源位与 `fetch_ffmpeg.sh` 获取脚本。

## 2.1 数据目录（已完成）

- 打包版 DB 与演示素材写入用户目录（`app.getPath("userData")`），不向只读 .app 包内写数据。

## 3. macOS 签名与公证

- 生成 Developer ID Application 证书，配置 electron-builder：`mac.identity`、`mac.hardenedRuntime: true`、`mac.entitlements`（仅必要权限）。
- 公证：`mac.notarize`（Apple ID / App Store Connect API Key），或打包后 `xcrun notarytool submit`。
- 验证：`codesign --verify --deep --strict`、`spctl --assess`。

## 4. Windows 打包

- 配置已就绪（`win.target: nsis`、`win.icon: icon.ico`、sidecar 名 `cthulhu-backend.exe`）。
- PyInstaller 不支持跨平台构建：Windows 包需在 Windows 机器上执行 `pnpm package`（先 `pnpm package:backend`）。
- 待办：Windows 代码签名证书；如面向对外分发还需考虑杀软误报与信誉积累。

## 6. 云端 CI 构建（已配置）

`.github/workflows/package.yml` 提供三平台矩阵打包：推送到 GitHub 后，
在云端并行构建 Apple Silicon mac（dmg）与 Windows（nsis）安装包，
自动完成依赖安装、静态 FFmpeg 下载、前端构建、PyInstaller sidecar 与
electron-builder 打包，产物作为 Actions artifact 下载。

- 触发方式：`git tag v0.1.0 && git push origin --tags`，或在 Actions 页面手动
  Run workflow。
- Intel mac 无云 runner（GitHub 已退役 Intel 机型），需在本地 Intel mac 上执行
  `FETCH_PLATFORM=darwin-x64 bash packaging/fetch_ffmpeg.sh && pnpm package`。
- 云端 PyPI 走官方源（workflow 内覆盖），本地开发仍用清华镜像。
- Windows 构建机无需手动下载 ffmpeg：脚本的 win64 分支自动从 BtbN 获取。
