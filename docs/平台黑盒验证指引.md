# 平台黑盒验证指引

> 通杀矩阵是必要条件而非充分条件。最终验收以平台是否不再判定
> 「重复素材 / 同一来源」为准，需在真实平台做黑盒测试。

## 1. 测试目标

验证清洗后的素材在目标平台（抖音 / 快手 / 视频号 / 小红书）上，
不再被识别为与源素材重复或同一来源。

## 2. 准备

1. 取一段你确认会被平台判定重复的素材（或此前被判重复的素材）。
2. 用本工具分别以轻度 / 平衡 / 深度三档清洗，得到三个产物。
3. 同时保留一份仅转码、不做清洗的对照（用于排除转码本身的影响）。

## 3. 执行

- 在目标平台分别上传：原始素材、仅转码对照、三档清洗产物。
- 观察指标：是否触发「重复 / 搬运 / 非原创」提示、流量是否受限、
  是否被归并到同一内容指纹。
- 单次结果可能有随机性，建议每个档位换账号或隔天复测 2~3 次。

## 3.1 对抗矩阵（2026-08-21 修订）

兵器库已覆盖几何/空域/频域/色度/时域/编码域，测试必须同时做两件事：
「全组合是否通杀」与「逐原语隔离归因」。只测全组合，即使通过也不知道
哪个手段有效；只测单原语，会漏掉组合效应。

基准配置 A0（对照组）：

| 编号 | 配置 | 目的 |
|---|---|---|
| A0 | 仅重编码（fast，无任何变换） | 排除重编码本身的影响 |
| A1 | 基础档（重排/变速/调光/锐化/音频重混） | 现状默认档 |
| A2 | A1 + 几何抗档（旋转 2.2° + 裁剪 2% + pHash 签名 ε0.04） | 哈希层主攻组合 |
| A3 | A2 + 全兵器（镜像/平移抖动/透视/噪声/像素与 DCT 重量化/色度量化/抽帧复制/转码链） | 通杀候选 |

逐原语隔离组（在 A1 基础上只加一项）：

| 编号 | 单项 | 假设的对抗对象 |
|---|---|---|
| G1 | 旋转 2.2° | 经典哈希对齐 |
| G2 | 平移抖动 1% | 块对齐/同步码 |
| G3 | 透视剪切 1% | 几何同步 |
| G4 | 水平镜像 | 方向敏感指纹 |
| S1 | DCT 重量化 step12 | QIM/频域载荷 |
| S2 | 中值滤波 3×3 | 冲激型空域水印 |
| S3 | 高斯噪声 0.02 | 扩频水印 |
| C1 | 色度量化 32 级 | 色度域水印 |
| T1 | 抽帧复制 every7 | 帧间冗余/时域同步 |
| B1 | 跨 codec 转码链 | 量化域/GOP 相关 |

同一素材、同一账号权限、尽量同一时段上传，逐项记录平台反馈。

## 3.2 结果记录

每行记录：配置编号、素材 ID、平台、上传时间、判重提示、限流表现、
素材标签（如「暗水印搬运」）、备注。同一配置换账号/隔天复测 2~3 次取众数。
把「有效单项」筛出来之后，再做两两/三三组合回归，收敛出最小且有效的
配置集，而不是把全兵器当默认档。

## 4. 判定

- 清洗产物通过、对照未通过 → 清洗有效，参数档位可用。
- 两者都未通过 → 平台判定不依赖我们覆盖的水印维度，需反馈给研发
  （提供该素材与平台处理结果，用于扩展基准库）。
- 两者都通过 → 该素材本身未被判定重复，换用已知被判重复的素材重测。

## 5. 记录要求

每次测试记录：素材标识、平台、上传时间、是否触发重复判定、
流量表现、所用档位。结果汇总到 data/samples/ 目录下的黑盒记录文件，
作为基准库扩展与档位校准的依据。
