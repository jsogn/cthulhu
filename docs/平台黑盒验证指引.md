# 平台黑盒验证指引

> 通杀矩阵是必要条件而非充分条件。最终验收以平台是否不再判定
> 「重复素材 / 同一来源」为准，需在真实平台做黑盒测试。

## 1. 测试目标

验证清洗后的素材在目标平台（抖音 / 快手 / 视频号 / 小红书）上，
不再被识别为与源素材重复或同一来源。

## 2. 准备

1. 取一段你确认会被平台判定重复的素材（或此前被判重复的素材）。
2. 用本工具分别以轻度 / 平衡 / 深度三档清洗，得到三个产物。
3. 同时保留一份仅转码、不做清洗的对照（用于排除转码本身的影响）。

## 3. 执行

- 在目标平台分别上传：原始素材、仅转码对照、三档清洗产物。
- 观察指标：是否触发「重复 / 搬运 / 非原创」提示、流量是否受限、
  是否被归并到同一内容指纹。
- 单次结果可能有随机性，建议每个档位换账号或隔天复测 2~3 次。

## 4. 判定

- 清洗产物通过、对照未通过 → 清洗有效，参数档位可用。
- 两者都未通过 → 平台判定不依赖我们覆盖的水印维度，需反馈给研发
  （提供该素材与平台处理结果，用于扩展基准库）。
- 两者都通过 → 该素材本身未被判定重复，换用已知被判重复的素材重测。

## 5. 记录要求

每次测试记录：素材标识、平台、上传时间、是否触发重复判定、
流量表现、所用档位。结果汇总到 data/samples/ 目录下的黑盒记录文件，
作为基准库扩展与档位校准的依据。
