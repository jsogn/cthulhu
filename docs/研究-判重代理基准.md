# 研究笔记：本地判重代理基准 v1

> 状态：已实现并完成首轮验证。代理栈只代表“主流判重思路”，不代替平台实测。

## 1. 目标

用一个可复现的本地代理栈量化两件事：

- 两段视频的重复度（原片 vs 平台下载版、原片 vs 清洗产物）；
- 每个对抗原语/参数档对判重栈的破坏力（清洗前后距离变化）。

解决此前“加参数凭感觉”的问题，为多版本候选排序和档位调参提供量化依据。

## 2. 代理栈组成

实现于 `evaluate/dedup_harness.py`，CLI 入口：

```bash
uv run --project backend cthulhu dedup-fingerprint <视频>
uv run --project backend cthulhu dedup-compare <原片> <候选> --out-dir docs/baselines --tag xxx
```

| 维度 | 实现 | 权重 |
| :--- | :--- | :--- |
| 图像感知哈希 | pHash / dHash / wavelet / block-mean，逐帧汉明距离（±30 帧错位容差） | 0.6 |
| 音频指纹 | 60s 对数梅尔谱中位数二值化指纹 | 0.3 |
| 镜头结构 | 采样窗口切点向量差异 | 0.1 |

### v1.1 增强（2026-08-24）

- 采样窗口从 2×12 帧增加到 5×14=70 帧，降低内容节奏带来的方差。
- 新增 **CLIP ViT-B/32 深度嵌入维度**（本地 ONNX，512 维余弦距离），
  权重：图像 0.35 / 时序 0.15 / 深度 0.25 / 音频 0.15 / 结构 0.1；
  模型缺失时自动回退到手工特征权重。
- 纯函数回归测试入库：`backend/tests/test_dedup_harness.py`（哈希位长、
  确定性、相同/无关帧距离语义）。

### 深度嵌入的首个关键发现

对 0608 轻+产物：手工特征把风险压到约 0.30，但 CLIP 余弦距离仅 0.025
（相似度 0.975），加入深度维度后风险回升到约 0.58。**几何/像素级扰动对
语义级 embedding 几乎无效**，与预期一致；平台若采用 CLIP 级向量，内容保持
型变换的逃逸下限约为 0.5~0.6。真实解法依赖内容级变化（构图、字幕、镜头
重组）或“不同账号用不同版本”的多版本策略，两者都有观感成本，需在
平台真值下权衡。

### 三档标定（3 片段 × 2 种子，含深度维度，2026-08-24）

| 预设 | 风险均值 ± 波动 | SSIM 均值 | 结论 |
| :--- | :--- | :--- | :--- |
| 轻+ | 0.675 ± 0.041 | 0.633 | 观感最好，逃逸有限 |
| 日常 | 0.604 ± 0.031 | 0.590 | 中间档 |
| 强 | 0.563 ± 0.031 | 0.539 | 逃逸最强，观感损失明显 |

多片段多种子后波动收窄到 ±0.03~0.04，标定可用；CLIP 维度把内容保持型
变换的风险下限钉在 0.53~0.68，印证“语义级指纹是硬墙”。GUI 标准档位于
轻+与日常之间，保守可用；向下的进一步降低依赖内容级重做或多版本分发。

距离用“无关联内容”的经验锚点归一到 0~1 后加权为 duplicate_risk；
锚点来自不同素材实测（phash 0.50 / dhash 0.35 / whash 0.38 / blockhash 0.34 /
audio 0.54 / structure 0.09），后续拿到平台真值样本再标定。

## 3. 首轮验证（2026-08-24）

| 对比 | 图像距离（pHash） | 音频距离 | duplicate_risk | 判定 |
| :--- | :--- | :--- | :--- | :--- |
| 0608 原版 vs 平台下载版 | 0.0007 | 0.0203 | 0.983 | 高（转码几乎不改指纹） |
| 0608 vs 0702（不同片） | 0.482 | 0.536 | 0.052 | 低 |
| 0608 30s 原片 vs 轻度攻击（1.05 变速+1.2% 裁剪+1.1° 旋转+微调色+atempo） | 0.207 | 0.136 | 0.463 | 中 |

结论：

1. 代理栈对“平台转码”给出 0.98 的重复度，对“不同内容”给出 0.05，区分度可用。
2. 轻度攻击能把重复度从 0.98 压到 0.46，但仍是“中”，说明轻档在感知哈希层
   不足以完全脱离判重栈；这正好给出调参方向：图像层需要更强的几何/亮度扰动，
   音频层 atempo 后仍保 0.75 归一化相似度，也需要更强重混。
3. 下一步把该代理栈接入候选生成排序：候选按“低判重风险 × 高画质”双目标排序。

## 4. 已知局限

- 采样窗口基于绝对时间，强变速会造成窗口内容错位（±30 帧容差部分补偿）。
- 未接入深度嵌入模型；锚点为静态常数，尚未用平台真值标定。
- 平台若用 CLIP 级语义向量，pHash 族的区分度会低估，后续可加本地 ONNX 嵌入
  维度（权重模型需另行选定）。
