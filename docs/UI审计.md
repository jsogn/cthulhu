## 二、demo 中保留但与 PRD 无冲突的内容

- 三栏工作台（素材库 / 预览对比 / 上下文面板）、双主题、风险筛选、导入弹窗、任务中心模拟、处理历史、设置。
- 前后对比滑杆、水印区域框选/拖拽/缩放、时间轴打点、快捷键。

## 三、本轮实现清单

- 新增底部全局状态栏（`ui/src/components/StatusBar.tsx`）。
- 工作台右面板：场景模板选择器、三档清除强度 Tab 与参数对照、检测信息卡、盲检测、处理校验指标、抗二次检测增强、画质优化开关、编码参数与无损输出。
- 任务中心：优先级徽标、断点续传说明、导出日志。
- 模板页：对齐 PRD 三个场景模板及参数。
- 新增共享任务统计 store（`ui/src/stores/jobs.ts`），状态栏与任务中心联动。
