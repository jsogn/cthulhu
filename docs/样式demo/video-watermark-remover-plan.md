# 视频暗水印去除工具 — 产品与设计计划

> 本文件是下一步进入 Design mode 生成高保真桌面端原型（HTML）的源计划。请先审阅并编辑，确认后回复“计划确认，开始设计”。

## 1. 项目意图

一款运行在本机的桌面软件，面向短视频 / 广告投放素材处理场景。核心能力分三层：一是批量导入与素材库管理，支撑素材团队成批作业；二是去除视频画面上可见的暗色水印（台标、Logo、字幕条、角标）并做区域内容修复；三是检测与提示千川 / 巨量等平台的“暗水印”（防搬运隐形指纹），在素材版权自有或已获授权的前提下，提供降低检测命中率的合规清洗工作流。批量能力贯穿全流程：批量导入 → 批量扫描 → 批量处理 → 批量导出，配套队列调度、模板复用与合规留痕。

- 技术栈：TypeScript + React + 2026 年主流的桌面与前端方案
- 本阶段交付：产品计划 → 高保真可交互桌面端原型 → 可运行工程骨架
- 设计语言：shadcn/ui + Tailwind CSS，社区流行的现代工具风格，内置暗黑 / 浅色双主题
- 边界：本工具定位为“可见水印修复 + 暗水印风险检测与合规清洗”，不承诺绕过平台风控（详见第 2 节）
- 批量优先：批量导入、批量扫描、批量处理与批量导出是一等公民能力，而非单条流程的附庸

## 2. 对“暗水印”的正确理解（千川 / 巨量等防搬运场景）

### 2.1 概念区分

- 明水印（可见）：画面角落的台标、Logo、文字条，肉眼可见，可用区域修复去除
- 暗水印（隐形指纹）：肉眼不可见，嵌入视频底层数据，用于溯源与防搬运
- 内容指纹（查重）：平台对画面内容本身的相似度匹配（相似分镜判断、MD5、关键帧抽样、多模态特征），与“水印”独立但常叠加生效

### 2.2 平台背景（2026 年时间线，平台公开治理信息）

- 抖音 / 巨量体系 2026 年 3 月底实装“暗水印”能力：原创客户上传的原件会被打上专属暗水印，正常进入投放环境
- 生效范围：巨量营销、巨量本地推（首批）、巨量千川（第二批）；2026-03-31 至 04-27 为披露提示期，之后正式治理
- 判定规则：素材文件层检测到非本账号暗水印即判搬运打压；默认开启、自动生效、不可申诉；与相似分镜同时命中时优先暗水印治理
- 官方口径：即使深度二创（调色、裁切、变速、加画中画、滤镜），暗水印信号仍可能保留；直播切片类（第三方抓取录屏再剪辑）目前不在搬运范围

### 2.3 技术形态（行业公开认知，细节需实测验证）

| 层 | 形态 | 说明 |
|---|---|---|
| 频域 | DCT 系数嵌入隐形指纹 | 上传转码时嵌入，相当于“电子身份证”；裁剪、调色、调速、压缩、二次录屏都难彻底破坏 |
| 检测方式 | 全局序列 + 单帧抽检 | 既匹配整段视频的水印序列，也抽检单帧残留信号，双重判定 |
| 容器层 | 元数据 / SEI 等 | 部分方案在 MP4 box、H.264 / AV1 SEI 等位置携带标识，重封装可清除但非根治 |
| 内容指纹 | 画面相似度 / MD5 / 关键帧 | 与暗水印独立；即使水印被破坏，画面高度相似仍可能命中 |
| 音频层 | 频谱指纹 | 音频指纹也可能参与多模态溯源 |

### 2.4 对产品能力的结论

- “去除暗水印”≠“去除角标”：常规剪辑工具只改表层像素，触及不到频域底层；不存在可靠的“一键无痕去除”方案
- 可行的方向是“合规清洗”：打散帧时序 / 分镜重构、修改单帧频域特征（画质微扰）、音频指纹同步处理，或直接以 AI 原生生成替换画面——前提是素材版权自有或已获授权
- 因此产品核心差异化是：可见水印修复（确定可行）+ 暗水印风险检测与清洗建议（诚实告知边界），而不是承诺“洗掉基因”

## 3. 目标用户与核心场景

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 内容创作者 / 剪辑师 | 素材里带平台台标或旧字幕条 | 快速批量去水印，画质损失小 |
| 二创作者（素材自有或已授权） | 下载素材带角标或疑似带暗水印 | 框选即导出，操作简单 |
| 千川 / 巨量投手与素材团队 | 投放素材被误判搬运、或需清洗已授权素材的暗水印 | 检测暗水印风险、合规清洗、降低误判 |
| 企业素材运营 | 历史视频带旧品牌水印 | 批量队列处理、统一导出规格 |

### 3.1 角色分工

| 角色 | 关注点 | 使用方式 |
|---|---|---|
| 素材运营 / 投手 | 投放前过检素材库，降低搬运误判风险 | 批量扫描、按风险报告筛选与处理 |
| 剪辑师 / 处理专员 | 去水印与清洗的效率和稳定性 | 批量套模板、队列处理、失败重试 |
| 质检 / 交付 | 质量与合规留痕 | 处理前后对比、风险报告与审计日志导出 |
| 负责人 | 业务成本与合规风险 | 素材来源登记、审计追溯、批量汇总报告 |

## 4. 功能范围

### MVP（原型必须覆盖）

- 批量导入与素材库
  - 多选文件 / 文件夹拖拽导入，自动解析元信息（时长、分辨率、帧率、大小），去重与格式校验
  - 素材库管理：搜索、筛选、标签、来源登记（自有 / 已授权 / 待确认），关联授权文件
  - 导入即批量扫描：整批自动产出暗水印风险报告，无需逐条操作
- 可见水印修复（明水印，单条精修）
  - 水印定位：自动检测画面中稳定的暗色区域 + 手动框选（多区域、每区域可设生效时间范围）
  - 区域修复：快速模式（FFmpeg delogo / OpenCV TELEA / NS）+ 精细模式（AI inpainting，如 LaMa）
- 暗水印风险检测（平台隐形指纹）
  - 扫描维度：频域异常、容器元数据 / SEI 残留、音频指纹、内容指纹提示
  - 批量风险报告：按素材列表呈现风险等级（低 / 中 / 高）与命中维度，支持一键筛选与批量打标
- 合规清洗工作流（版权自有 / 已授权前提下）
  - 分镜重构：拆解分镜、乱序重组、时长调整、插入转场
  - 画质微扰：可调强度的全域微调，改变单帧频域分布
  - 音频指纹同步处理
- 批量任务队列与调度
  - 任务状态机：排队 → 扫描 → 处理 → 导出 → 成功 / 失败，全程可见
  - 暂停 / 恢复 / 取消 / 重试、优先级调整；单条失败隔离，不影响整批
  - 并行调度：可配置并行数与 GPU 占用上限；断点续传，重启后可恢复
- 批量处理模板
  - 参数预设（水印区域、修复模式、清洗强度、导出设置）可保存 / 复用，一键应用到整批素材
- 批量导出
  - 统一输出目录结构（按批次 / 日期 / 任务），命名规则可选（前缀 / 时间戳 / 原文件名）
  - 导出后自动汇总报告：成功 / 失败 / 风险残留统计
- 预览对比：单条处理前后同帧滑杆对比、逐帧浏览、检测前后对比
- 合规留痕
  - 素材来源登记与授权文件关联；审计日志记录“谁在何时用何参数处理了哪些素材”
  - 单条 / 批量风险报告与审计日志可导出（供质检与申诉留档）

### 后续（不在本期原型）

- AI 原生生成替换素材（从源头无暗水印）
- 隐形数字水印深度去除研究（实测验证可行的特定指纹方案）
- 多人审批流与任务分配
- 字幕识别与替换
- GPU 实时预览
- 平台直连校验（可选）

## 5. 核心用户流程

### 5.1 单条精修流程

1. 导入视频 → 解析元信息 → 自动扫描暗水印风险（频域 / 元数据 / 音频）→ 出现在项目列表
2. 查看检测报告 → 确认风险等级与命中维度 → 选择“仅可见水印修复”或“合规清洗”
3. 打开编辑器 → 自动检测或手动框选可见水印区域 → 调整时间范围与修复模式
4. 合规清洗（可选）→ 分镜重构 / 画质微扰参数 → 预览对比 → 确认效果
5. 加入处理队列 → 查看进度 → 完成后打开导出目录 / 定位文件

### 5.2 批量处理流程（核心业务流）

1. 批量导入：多选文件 / 拖入文件夹 → 自动解析与去重 → 批量扫描暗水印
2. 查看批量风险报告 → 按风险等级 / 命中维度筛选 → 打标签、登记素材来源
3. 应用处理模板（可见水印区域 + 修复模式 + 清洗强度 + 导出设置）→ 勾选素材 → 加入队列
4. 队列并行处理 → 实时进度 → 失败自动隔离、可单独重试
5. 批量导出 → 生成汇总报告与审计日志 → 交付质检 / 投放

## 6. 信息架构与页面结构

桌面单窗口、多视图（侧边导航切换），核心为三栏工作台：

- 左侧栏：素材库（文件夹 / 标签 / 来源筛选）、批量操作、设置入口
- 中央区：视频预览（播放 / 暂停 / 拖帧 / 对比滑杆）、水印框选画布
- 右侧栏：选中水印的属性（位置、尺寸、时间范围、修复模式）、检测结果摘要、清洗参数、导出参数

视图清单：

- 素材库：导入入口、批量扫描入口、搜索 / 筛选 / 标签、来源登记
- 编辑器：预览 + 框选 + 参数调整
- 检测报告：单条风险评分卡与批量风险列表、命中维度明细、频域热区、清洗建议
- 批量任务中心：队列、并行调度、失败重试、汇总报告
- 模板管理：参数预设的保存 / 复用
- 审计日志：操作留痕与导出
- 设置：默认导出目录、格式、并行数、GPU 开关、临时目录

## 7. 布局、组件与状态要求

组件（基于 shadcn/ui 原语构建）：

- 拖拽上传区、文件卡片、水印选区画布（可缩放预览）
- 时间范围双滑块、前后对比滑杆、任务进度卡片、导出格式选择器
- 风险评分卡、频域热区图、清洗参数面板
- 批量导入弹窗（多文件 / 文件夹、去重与格式校验结果）
- 批量风险列表（等级徽标、命中维度、筛选与批量打标）
- 队列卡片（状态、进度、优先级、重试）
- 模板选择器与批量参数面板
- 审计日志表

任务状态机：

- idle → scanning（暗水印扫描中）→ detecting（可见水印识别中）→ reviewing（待确认）→ processing（处理中 x%）→ exporting → done / error
- 每个状态都有明确视觉反馈与可操作按钮（重试、取消、查看详情）

交互规则：

- 所有可点击目标 ≥ 44px；键盘可聚焦，`:focus-visible` 有清晰焦点环
- 暗黑 / 浅色双主题下正文对比度 ≥ 4.5:1，状态色成对设计，hover 不得降低前景对比
- 批量处理支持取消与暂停恢复
- 批量操作全程可中断：暂停 / 恢复 / 取消，关闭应用不丢任务
- 批量选择支持勾选、全选、按风险等级反选

## 8. 技术架构（2026 年主流选型）

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面壳 | Tauri 2（Rust）首选，Electron 备选 | 包体小、内存占用低；视频处理放 Rust 侧 |
| 前端 | React 19 + TypeScript + Vite | 组件化 + 类型安全 |
| 样式与组件 | shadcn/ui（Radix 原语）+ Tailwind CSS 4 | 社区流行组件语言，CSS 变量驱动双主题 |
| 状态管理 | Zustand | 轻量，适合桌面工具 |
| 视频处理 | Rust + FFmpeg 管线 + OpenCV Inpainting，可选 ONNX Runtime（LaMa） | 逐帧修复，进度通过 IPC 事件流推送 |
| 暗水印检测 | Rust + FFmpeg 解流 + DCT / 频域分析 + 元数据 / SEI 检查，可选 ONNX Runtime 模型 | 输出风险评分与命中维度 |
| 合规清洗 | 分镜拆解 + 乱序重组 + 画质微扰 + 音频频谱处理 | 可调强度，优先保持观感 |
| 任务队列与调度 | Rust（Tokio）+ SQLite，IPC 事件流 | 并行数可配、优先级、断点续传、失败隔离 |
| 批量扫描 | 批量解流 + DCT / 元数据 / 音频分析队列 | 队列化执行，避免卡住 UI |
| IPC | Tauri commands + events | 异步任务与进度回调 |
| 持久化 | SQLite（tauri-plugin-sql）或 JSON 项目文件 | 项目、任务、设置 |

## 9. 视觉方向

- 基调：社区流行的现代极简工具风格（Linear / Vercel 一类），中性底色 + 细边框 + 低饱和强调色，避免“AI 模板感”与中后台表格密集感
- 组件语言：shadcn/ui 原语（Radix 无障碍基础）+ Tailwind CSS 4，通过 CSS 变量（OKLCH）管理 token；进入 Design mode 时输出完整 token 表并锁定
- 双主题：暗黑 / 浅色双模式，默认跟随系统、可手动切换；两套主题共用同一 token 结构，仅映射值不同
- 字体：中文 UI 用系统字体栈（PingFang SC / Microsoft YaHei），数字与时间码用等宽字体（如 JetBrains Mono）
- 布局系统：三栏固定工作台，预览区为视觉中心；导出等主操作保持单主按钮
- 反模式规避：无渐变紫、无多余装饰动效；框选与对比交互优先保证可用性

## 10. 数据与内容模型（原型标注用）

- Project：id、名称、源文件路径、时长、分辨率、帧率、水印区域列表、创建时间
- WatermarkRegion：id、x / y / w / h（归一化坐标）、开始 / 结束时间、修复模式、是否自动检测
- ScanReport：projectId、风险等级、命中维度（频域 / 元数据 / 音频 / 内容指纹）、置信度、清洗建议
- MaterialAsset：id、源路径、时长、分辨率、帧率、标签、来源类型（自有 / 已授权 / 待确认）、授权文件、扫描报告引用
- BatchJob：id、名称、状态、进度、并行数、模板引用、Task 列表、导出目录、汇总报告
- Template：id、名称、水印区域列表、修复模式、清洗强度、导出设置
- AuditLog：时间、操作者、素材 / 批次、参数快照、结果
- CleanConfig：重构强度、微扰强度、是否处理音频指纹
- Task：id、projectId、状态、进度、模式（repair / clean）、输出路径、错误信息
- Settings：默认导出目录、默认格式、分辨率策略、GPU 开关、临时目录
