## 1. 项目目的

Cthulhu 是一个用于**数字水印、内容指纹、媒体取证与视频变换鲁棒性**的研究与
学习实验项目。项目目标是帮助研究者、学生和工程实践者理解：

- 数字水印与内容指纹的基本原理、检测方法与鲁棒性边界；
- 视频编码、几何变换、时域处理和音频处理对媒体特征的影响；
- 本地代理指标、差分分析、误码率、画质指标等研究方法的适用条件与局限；
- 如何在可复现、可审计、合规的实验环境中记录和验证结论。

本项目不是面向生产环境的商业化规避工具，不提供任何平台审核通过、流量提升、
账号安全或内容分发效果的承诺。

## 2. 允许的使用范围

仅允许在以下范围内使用本项目及其文档：

1. 学术研究、课程教学、个人学习和算法原理验证；
2. 使用合成样本、自有素材、已获明确授权的素材和测试账号；
3. 在隔离的实验环境中进行数字水印嵌入、检测、鲁棒性评估和画质分析；
4. 对公开算法、公开论文或自建基准库进行可复现实验；
5. 在获得平台明确授权或使用平台提供的测试接口/沙箱时，开展合规性研究。

任何实验都应保留素材来源、授权范围、处理参数和评估口径，确保结果可追溯。
