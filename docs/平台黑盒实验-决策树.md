# 平台规则合规性研究：历史决策树已废止

> **研究用途声明**：本文仅用于数字水印、内容指纹与媒体变换的研究、教学和
> 授权测试。严禁用于规避平台规则、去除版权/溯源水印、侵权搬运、账号矩阵
> 规避或其他违法违规用途。完整边界见
> [研究用途与合规声明](研究用途与合规声明.md)。

## 1. 状态说明

早期版本的 A0/B/C 决策树以“上传不同变体、判断平台是否识别”为核心，容易被
误解为平台规避操作指南。该实验方法现已废止，不再作为项目指导文档使用。

## 2. 保留的研究问题

以下问题可以在授权测试环境中研究，但不得用于规避平台规则：

- 本地代理指标与平台公开反馈之间是否存在系统性偏差；
- 编码、分辨率、时域结构等公开因素如何影响内容相似度代理指标；
- 合成样本与真实素材在鲁棒性评估中的差异；
- 评估方法本身的置信区间、样本量和随机性问题。

## 3. 合规约束

1. 仅使用自有、已授权或平台提供的测试素材；
2. 仅使用平台明确允许的测试账号、接口或沙箱；
3. 不针对真实账号、真实投放或真实风控系统进行规避性测试；
4. 不记录、不传播可用于规避平台规则的参数组合或操作步骤；
5. 不将任何结果宣传为“保证过审”“保证不限流”或“保证不被识别”。

## 4. 替代做法

优先使用以下研究路径：

- 自建合成水印基准库与公开算法实现；
- 本地代理指标、差分分析和鲁棒性矩阵；
- 公开数据集上的可复现实验；
- 平台明确提供的测试接口或学术合作渠道；
- 对平台规则、版权和隐私边界进行合规审查后再设计实验。
