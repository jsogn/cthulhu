# 平台黑盒实验：A0 / B / C 决策树

> 2026-08-31 建立。目标：用一次最小黑盒实验，判定平台"暗水印/搬运"判据
> 到底落在哪一层，从而决定产品的主攻方向。本实验不依赖任何本地检测分数。

## 1. 实验前提（合规边界）

- 仅使用有授权的内容与测试账号；样本登记沿用 `data/samples/README.md` 的
  使用规则，不对外分发。
- 同一素材的变体尽量同账号、同时段上传，不同配置换账号/隔天复测 2~3 次
  取众数（沿用《平台黑盒验证指引》3.2 的结果记录要求）。

## 2. 三个变体

| 编号 | 含义 | 生成方式（以 AD-下载8 原片为例） |
| :--- | :--- | :--- |
| A0 | 仅转码，不做任何处理 | `ffmpeg -i 原片 -c:v libx264 -preset veryfast -crf 23 -c:a aac -b:a 96k A0.mp4` |
| B | 全兵器但不重排内容（画面叙事不变，含基础档 recrop 3% / 调光 / 锐化 / 色彩还原 + 指纹对抗与全部信号武器） | `services.run_desensitize`，rotate=0.3 / phash_attack / phash_epsilon=0.05 / multi_hash_attack / dct_step=12 / requant=32 / chroma_levels=32 / noise=0.008 / subtract_beta=1.2 / transcode_chain=True / denoise=True / anti_reembed=True / audio_strong=True |
| C | 内容级改造（只动可见内容，不加信号武器） | `services.run_desensitize`，reorder=True / shot_retime=True(0.97~1.06) / cut_jitter=2 / recrop=0.04 / regrade=True / sharpness=True / color_restore=True / audio_remix=True，denoise/requant/noise/dct_step 全部关闭 |

关键控制变量：

- A0 隔离"重编码本身"的影响；
- B 隔离"内容重排之外的一切攻击"的影响（叙事顺序不变）；
- C 隔离"内容级改造"的影响（画面可见内容改变，但不用信号武器）。

 三者只有都跑过同一平台同一账号流程，才能把判据归因到单一层。若 B 通过，
 用《平台黑盒验证指引》的逐原语隔离组（G1~B1）做二次归因，定位具体有效武器。

## 3. 执行步骤

1. 准备原片与 A0/B/C 四个文件（本地生成，见上表）。
2. 上传原片，确认该素材在该平台**确实会被判"暗水印/搬运"**（先拿到阳性
   基准，否则实验无效）。
3. 依次上传 A0、B、C，记录每个是否被判。
4. 按第 4 节决策树解读，把结果写入 `data/samples/` 黑盒记录文件。

## 4. 决策树

```text
原片被判（阳性基准成立）后：

A0 通过   → 判据弱（重编码即可破坏）→ 信号层还有得打，回到水印路线
A0 被判   → 判据强，继续看 B/C
  B 通过 → 信号级攻击有效 → 主攻方向 = 信号层（现有兵器库即可）
  B 被判 → 信号级攻击无效（与本地结论互证）
    C 通过 → 判据在"人眼可见内容/指纹"层 → 主攻方向 = 内容级改造
    C 被判 → 判据在账号/设备/文件身份层 → 清洗原理上不可解决，
             产品承诺收窄，停止"必过"诉求
```

## 6. 与已有文档的关系

- 本实验是《平台黑盒验证指引》对抗矩阵的**最小决策版**：先做归因，再做
  全组合；避免在未归因前继续堆参数。
- 本地检测器只做回归，口径以《研究-盲检测基线》v7 为准。
