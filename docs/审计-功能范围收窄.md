# 审计：功能范围收窄（2026-08-24）

> **研究用途声明**：本文仅用于数字水印、内容指纹与媒体变换的研究、教学和
> 授权测试。严禁用于规避平台规则、去除版权/溯源水印、侵权搬运、账号矩阵
> 规避或其他违法违规用途。完整边界见
> [研究用途与合规声明](研究用途与合规声明.md)。

> 研究原则：项目只做「水印鲁棒性变换 / 内容指纹相似度分析」本身；A/B 实验
> 由研究者在授权环境中自行设计与统计，我们提供的是可复现、可追溯的实验结果，
> 不做实验管理平台，也不提供平台规避指导。

## 保留（需要）

| 能力 | 理由 |
| :--- | :--- |
| 产物参数快照（variants 表） | 用户拿产物对照时能回答“它是什么参数生成的”，是追溯的最低要求 |
| 产物参数查看 UI（处理产物·参数） | 快照对用户可见才有价值 |
| 相似度代理评分 | 变换效果的核心反馈：处理校验卡 + 候选排序（研究口径） |
| 快照补全 preset/strategy/gpu/版本 | 同一份快照跨构建可复现，避免“参数相同结果不同”的假象 |
| 导出复制产物 | 基础能力，不夹带实验文件 |

## 移除（过度设计）

| 项 | 原因 |
| :--- | :--- |
| 实验批次 / 变体标签输入 | 分组统计由用户自行进行 |
| 固定种子输入 | 用户确认随机即可，种子差异不影响档位效果 |
| 候选 base_seed API | 同上，保留随机出种 |
| 导出 manifest.json | 用户自行统计，不需要软件代打包实验清单 |
| A/B 协议 / 投放记录表 / 平台结果录入 | 不做实验管理，用户测出结论反馈后我们迭代 |

## 已明确不做

- 批量多版本实验矩阵、原片对照组管理、平台判定结果回传；
- 语义级“全方案覆盖”包装（CLIP 墙）、字幕 OCR 重排（先验实验已证无增益）。
