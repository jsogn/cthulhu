## 文档约定

1. **必须引用合规声明**：README、产品定位、实施指引、实验记录与发布说明都要显式
   链接 [研究用途与合规声明](研究用途与合规声明.md)。
2. **术语中性化**：新增文档优先使用「变换实验」「鲁棒性评估」「相似度分析」
   「基准库覆盖测试」等表述；历史文档中的「清洗」「去重」「攻击」等词仅描述变换
   处理与压力测试，不代表允许规避平台规则。
3. **结论标注边界**：任何数字都要写明样本规模、参数、随机性与局限，
   「基准库内有效」不等于「真实平台有效」。
4. **版本号唯一真值**：版本号只写在
   `backend/src/cthulhu_backend/version.py`，其余清单由
   `backend/scripts/sync_version.py` 派生，文档不再重复维护版本号。
5. **图片资产**：截图统一放在 `docs/assets/screenshots/`，文件命名
   `ui-<视图>.png`；提交前确认画面不含真实素材、真实路径与个人信息。
