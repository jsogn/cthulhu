# 研究笔记：对抗原语增强矩阵 v1

> 状态：新原语已实现并用判重代理基准完成首轮打分。

## 1. 新增原语

- `transform/video.per_shot_retime`：逐镜头 0.95~1.08 倍微变速，叙事顺序不变。
  比全片统一变速更能打散时间轴对齐。
- `transform/video.cut_jitter`：镜头首尾随机去掉 0~4 帧，轻微漂移切点，
  破坏结构指纹的切点序列。
- `transform/audio.remix_strong`：变速 + 变调 + 强 EQ 倾斜 + 底噪，
  针对音频指纹的时间-频率对齐做双重扰动。
- `evaluate/attack_matrix.py`：双目标打分驱动（判重风险 × 画质/叙事连续性）。

CLI：

```bash
uv run --project backend cthulhu attack-matrix <短片段> --out-dir <目录> [--reuse]
```

## 3. 解读

1. 逐镜头变速 + 切点漂移 + 强音频重混把代理判重风险从 0.98 压到 0.35~0.45，
   图像与音频两维都产生了可测量距离。
2. 对齐 SSIM 是保守下界：逐镜头变速使帧映射非线性，搜索窗口 ±4 帧仍可能
   错配；真实观感优于该数值。叙事连续性 0.94~0.98，顺序未被破坏。
3. 强档的 SSIM 明显低于轻+，符合“研究/极限”定位；面向日常的档位应在
   轻+ 与 强 之间再取一点（预计风险 0.40 附近、SSIM ≥0.7）。
